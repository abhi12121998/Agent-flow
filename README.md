# Yuno — AI Agent Orchestration Platform

A full-stack platform for creating, configuring, and orchestrating AI agents into multi-agent workflows — with real LangGraph execution, PostgreSQL persistence, a visual workflow builder, and Telegram integration.

---

## Quick Start

**Requirements:** Python 3.10+, Node 18+, npm

```bash
git clone https://github.com/abhi12121998/Agent-flow.git
cd Agent-flow
./setup.sh
```

Open **http://localhost:5173** — register an account and start building agents.

---

## Language & Stack

**Python + FastAPI (Backend)**
Python is the natural home of the LangChain/LangGraph ecosystem. FastAPI provides native async support (essential for non-blocking LLM calls), automatic OpenAPI docs at `/docs`, and built-in WebSocket support. SQLModel gives type-safe models with Pydantic validation — one schema serves both DB and API.

**React + Vite (Frontend)**
ReactFlow is the leading open-source library for interactive node-based canvas UIs — exactly what a workflow builder needs. Vite provides instant HMR with minimal config.

---

## AI Framework: LangGraph

LangGraph was chosen over CrewAI, AutoGen, and a custom runtime because:

1. **Explicit graph topology** — each agent is a compiled `StateGraph` with an `agent ↔ tools` ReAct loop. Execution is deterministic and inspectable.
2. **Composable** — individual agent graphs stay self-contained and are composed at the workflow level by the `WorkflowRunner`, matching the visual node-based UI directly.
3. **Native tool use** — `ToolNode` + `bind_tools` gives clean ReAct loops without manual prompt engineering.
4. **Async-friendly** — runs in a thread pool via `run_in_executor`, keeping FastAPI non-blocking while WebSocket events stream in real time.


---

## LLM Provider: Groq

Groq offers a free API tier (no credit card required) making the platform immediately runnable. Its inference speed is significantly faster than standard endpoints, which improves the experience in the visual workflow builder.

Available models: `llama-3.3-70b-versatile` (default), `llama-3.1-8b-instant`, `mixtral-8x7b-32768`, `gemma2-9b-it`.

## Architecture

```
┌─────────────────────────────────────────────────────┐
│              React Frontend (Vite)                  │
│  AgentStudio │ WorkflowBuilder │ Monitor │ Channels │
└──────────────────────┬──────────────────────────────┘
                       │ REST + WebSocket
┌──────────────────────▼──────────────────────────────┐
│                  FastAPI Backend                    │
│                                                     │
│  Agent Manager · Scheduler · WebSocket Manager     │
│                                                     │
│  ┌─────────────────────────────────────────────┐   │
│  │          LangGraph Agent Runtime            │   │
│  │   agent_node  ◄──►  tools_node  (ReAct)    │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  Workflow Runner (topo-sort) · Memory Store        │
│  Telegram Channel · JWT Auth                       │
│                                                     │
│  PostgreSQL (Neon) / SQLite (local fallback)       │
└─────────────────────────────────────────────────────┘
```
